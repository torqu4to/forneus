# Awesome DESIGN.md references

This skill packages the `DESIGN.md` collection from [VoltAgent/awesome-design-md](https://github.com/voltagent/awesome-design-md). The reference files are in `references/<site>/DESIGN.md`.

1. Inspect the available site directories under `references/`, then read only the examples relevant to the task.
2. Compare visual theme, colors, typography, components, layout, and responsive behavior.
3. Choose and adapt useful principles for the project's own brand. Do not copy another brand's name, logo, or full visual identity by default.
4. Check the result against the existing project design and the user's instructions.
